# M6 — Interactive rebase and history editing from the Log

**Goal:** PyCharm's *Interactively Rebase from Here* editor plus the Log's one-shot history edits (squash, fixup, drop), all through `scripted_rebase` so each is a single undoable step.

## Backend
- `scripted_rebase.squash_plan(todo, shas)` — moves the selected commits next to the oldest one and marks the rest `squash`; returns the sha whose editor prompt receives the combined message.
- `scripted_rebase.fixup_plan(todo, target, fixup_sha)` — places a `fixup!` commit right after its target as `fixup`.
- `scripted_rebase.validate(todo)` — first item can't be squash/fixup; at least one non-drop item.
- `op.continue` during a rebase uses `scripted_rebase.resume()`, so reword/squash messages staged for later commits still apply after an `edit` stop or a conflict.

## Actions
| id | key | where | notes |
|---|---|---|---|
| `log.interactive_rebase` | `I` | log (one commit on the current branch) | opens the editor for `<commit>^..HEAD` |
| `log.squash` | `S` | log (≥2 commits on the current branch) | multi-line message prompt prefilled with the combined messages |
| `log.drop` | `D` | log | confirm, then drop |
| `log.fixup_staged` | `alt+f` | log (one commit) | commit staged changes as `fixup!` and autosquash into the selected commit |
| `rebase.start` | `ctrl+s` | rebase editor | runs the edited todo |

## UI — `screens/rebase_editor.py`
Full screen, oldest commit first. Keys: `p` pick, `r` reword (opens message editor), `e` edit, `s` squash, `f` fixup, `d` drop, `alt+↑/↓` (or `K`/`J`) move, `ctrl+s` start, `esc` cancel. Squash/fixup rows are indented under their target; dropped rows struck through; reworded rows show the new subject.

## Acceptance tests
1. `squash_plan` / `fixup_plan` / `validate` unit tests.
2. Actions: squash two non-adjacent commits with a message; drop; fixup staged changes into an older commit; each undoable in one step.
3. Editor-driven rebase: reorder + reword + drop; `edit` stop → banner → amend → Continue applies a later reword.
4. Pilot: Log → `I` → `d` on a row, `r` on another (message), `ctrl+s` → history matches.

## As built
- `scripted_rebase._drive` hands any stop it doesn't drive itself (an `edit` without a callback, `break`, a failed `exec`) back to the user as `status="stopped"`; the banner's Continue calls `resume()`.
- The editor publishes `todo`, `base` and `messages` in `ctx.form`; a squash group's message is keyed to the group's last commit because that's when git asks for it.
- `log.fixup_staged` uses `alt+f` so plain `F` keeps meaning Fetch everywhere.
