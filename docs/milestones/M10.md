# M10 — Patch builder, bisect, custom commands

## Patch builder (`git/patch_builder.py`)
Works on a `Selection` over a commit's diff (`CommitDiff(sha)`), always via `scripted_rebase` so each operation is one undo step:

| Function | Result |
|---|---|
| `remove_from_commit(session, sha, sel)` | the selected changes disappear from `sha` (and from history) |
| `move_to_new_commit(session, sha, sel, message)` | `sha` keeps the rest; a new commit with the selection follows it |
| `move_to_commit(session, sha, sel, target)` | selection removed from `sha` and amended into `target` (older or newer, same branch) |
| `move_to_index(session, sha, sel)` | removed from `sha`, then applied (staged) to the working tree after the rebase |
| `revert_in_worktree(git, sha, sel)` | reverse-applies the selection to the working tree (no history change) |

HEAD is handled without a rebase. Hunks that no longer apply where they're moved surface as a normal rebase conflict.

## Bisect (`git/bisect.py`)
`state(git)` (good/bad/skipped shas, current candidate, remaining estimate, first-bad result), `mark(git, verdict, sha=None)` (starts a bisect on the first mark), `skip`, `reset`, `run(git, cmd)` streaming output, `first_bad(git)`. `BisectMarkers` provider: `bad`, `good`, `skip`, `▶ testing` labels in the Log.

## Custom commands (`actions/custom.py`)
`[[commands]]` from config compile to `Action(id="custom.<id>")`:
```toml
[[commands]]
id = "open-pr"
label = "Open pull request"
key = "ctrl+o"
context = "branch"             # global | commit | branch | file | worktree
run = "gh pr view --web {branch}"
output = "none"                # none | popup | terminal
confirm = "Open a PR for {branch}?"   # optional
prompts = [{ name = "msg", label = "Message" }]   # → {msg}
read_only = true               # false (default) records it in the undo journal
```
Placeholders: `{repo} {worktree} {commit} {commits} {short} {branch} {ref} {file} {files} {count}` + prompts, all shell-quoted. Commands run with `sh -c` in the active worktree (the one documented exception to "only `Git.run` spawns processes").

## Actions
| id | key | where |
|---|---|---|
| `patch.remove` | `alt+r` | log/history diff selection |
| `patch.move_new` | `alt+n` | log/history diff selection (prompts for message) |
| `patch.move_to` | `alt+m` | log/history diff selection (choose target commit) |
| `patch.move_index` | `alt+i` | log/history diff selection |
| `patch.revert` | `alt+v` | log/history diff selection |
| `bisect.bad` / `bisect.good` / `bisect.skip` | `alt+b` / `alt+g` / `alt+k` | log (selected commit, default HEAD) |
| `bisect.run` | — | palette: prompts for a command, streams output |
| `bisect.reset` | — | banner Abort / palette |

## Tests
Patch builder: each operation on a 3-commit history (middle commit, HEAD), undo restores. Bisect: find the first bad commit by marking, by `run`; markers. Custom commands: placeholders/quoting, prompts, output modes via FakeUi, journal entry for non-read-only, config errors.
