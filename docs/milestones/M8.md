# M8 — Undo / redo UI

**Goal:** make the journal (recording since M1, `z`/`Z` since M1) visible and navigable.

- `Action.label_fn(ctx)` — optional dynamic label; the hint bar, palette and context menu show e.g. `z Undo "Commit: fix parser"` / `Z Redo "Drop 2 commits"`.
- `screens/journal.py` — Journal screen (`alt+z`, or "Operation history…" in the palette): every recorded operation newest first with time, what moved (`main 1a2b3c4 → 9f8e7d6`, `+feature`, `-old`), whether it backed up the working tree, failed or is undone. `enter` undoes everything down to and including the selected entry (or redoes up to it when it's undone); stops with the reason if a step is refused.
- `journal.undo_to(entry_id)` / `redo_to(entry_id)` in the backend.
- Startup prunes the journal and backup refs (`keep=200`, `max_age=30 days`, configurable in M9).

## Tests
1. `undo_to` across three entries; refusal midway leaves earlier entries intact; `redo_to`.
2. `label_fn` shows the next undo/redo op in the hints.
3. Pilot: two commits → `alt+z` → select the older → `enter` → both undone.
4. `prune` drops old entries and their `refs/gitpanel/backup/*`.
