# M7 — History, annotate, shelf, stash, changelists

## Backend
| Module | Contents |
|---|---|
| `history.py` | `file_history(git, path)` → `[FileRevision(commit, path, status)]` following renames; `selection_history(git, path, start, end)` via `git log -L`; `blame(git, path, rev=None)` → `[BlameLine(sha, author, time, summary, line, orig_line, orig_path, text)]` from `--porcelain` |
| `stash.py` | `stashes()`, `push(message, include_untracked, keep_index, paths)`, `apply(ref, restore_index)`, `pop`, `drop`, `branch(name, ref)` |
| `shelf.py` | PyCharm shelves: `Shelf` stored in `<common-dir>/gitpanel/shelf/<id>/` (`changes.patch`, `meta.json`: name, date, base sha, paths); `shelve(session, name, paths)` saves HEAD→worktree changes (incl. untracked) then rolls them back; `unshelve(shelf, paths=None, keep=False)` applies (`--3way` fallback) and removes the shelf unless kept or partial; `delete`, `list` |
| `changelists.py` | named changelists per worktree (`<git-dir>/gitpanel/changelists.json`): `lists`, `active`, `assign(paths, name)`, `rename`, `remove` (files go back to the default list), unassigned changed files belong to the active list |

## Actions
| id | key | where |
|---|---|---|
| `file.history` | `alt+h` | Commit window file, Log file, Annotate |
| `file.annotate` | `alt+a` | Commit window file, Log file (at that revision) |
| `annotate.previous` | `p` | annotate line → annotate the parent of the line's commit |
| `annotate.show_commit` | `enter` | annotate line → Log selects the commit |
| `annotate.selection_history` | `alt+h` | annotate with a line range |
| `shelf.shelve` | `alt+s` | Commit window (selected files / group) — asks for a name |
| `stash.push` | `alt+t` | Commit window — message, include untracked, keep index |
| `shelf.unshelve` / `shelf.delete` | `enter` / `d` | Shelf window |
| `stash.apply` / `stash.pop` / `stash.drop` / `stash.branch` | `a` / `enter` / `d` / `B` | Shelf window |
| `changelist.new` / `move` / `rename` / `delete` / `set_active` / `stage` | — / `f6` / … | Commit window |

## UI
- `screens/history.py` — pushed screen: revisions of a file (or a line range) with subject/author/date and the file's diff at each revision; `alt+a` annotates the selected revision, `G` gets the file from it.
- `screens/annotate.py` — pushed screen: gutter (short sha · author · date, coloured by age: green new → purple old) + file text; `v` range selection.
- `screens/shelf.py` — tool window tab "Shelf ⌥5": shelves and stashes in one list, diff of the selected entry.
- Commit window: unstaged changes are grouped by changelist (default list keeps the "Changes" title).

## Acceptance tests
1. `file_history` across a rename; `selection_history` returns only commits touching the range; `blame` attributes lines and handles uncommitted lines.
2. Stash push/apply/pop/drop/branch incl. untracked and keep-index.
3. Shelve two files (one untracked) → working tree clean → unshelve → restored; partial unshelve keeps the shelf.
4. Changelists: assign, persistence, removal returns files to default, active list collects new files.
5. Pilots: `alt+h` on a file → history screen lists revisions; `alt+a` → annotate shows authors; `alt+s` shelve → Shelf tab lists it → `enter` unshelves.

## As built
- History, Annotate, Resolver and Rebase editor are pushed `Screen`s exposing `context()`; opening a tool window from any of them pops back to the base screen first.
- Shelving/stashing/unshelving are `destructive` (a backup snapshot is taken) but use `silent_backup=True`, so they don't ask for confirmation.
- Changelists group only unstaged tracked changes (Staged and Unversioned keep their own groups); `f6` moves files, the rest is in `alt+enter` on a changelist node.
- Annotate gutter colours run from Hulk green (newest) to purple (oldest).
